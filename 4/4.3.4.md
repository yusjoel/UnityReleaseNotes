# Unity 4.3.4

The Unity 4.3.4 release brings you improved OS X Mavericks performance and a fix for iOS. Read the release notes below for details.

For more information about the previous main release, see the [Unity 4.3 Release Notes](https://unity.com/unity/whats-new/unity-4.3).

## Release notes

## Improvement

- Editor: Improved OS X Mavericks performance in the editor. Works around freezes and sluggish performance on some Mac configurations due to OpenGL driver issues

## Fixes

- iOS: Fixed case when big WWW downloads were silently failing
